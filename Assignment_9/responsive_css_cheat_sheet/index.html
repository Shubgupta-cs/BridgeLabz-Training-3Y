Responsive CSS Cheat Sheet

Quick reference guide for core responsive design concepts.

CSS Filters

filter: blur() | grayscale() | sepia()

Applies graphical effects like blurring or color shifting to elements.

Media Queries

@media (max-width: 768px)

Conditionally applies CSS rules based on device viewport dimensions.

Fluid Layouts

grid-template-columns: repeat(auto-fit, minmax(...))

Creates responsive grids that automatically wrap columns based on available space.

Responsive Typography

font-size: clamp(1rem, 2vw, 2rem)

Scales text smoothly between defined minimum and maximum size boundaries.
